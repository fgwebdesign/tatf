Introducción

Este informe presenta los resultados de la ejecución automatizada de las pruebas funcionales de la aplicación AdminCES, agrupadas en suites y ejecutadas en dos navegadores (Chrome y Firefox).

  • Documento de parametrización: los datos de las pruebas (nombres, países, perfiles, contraseñas) están en archivos CSV y los textos esperados y la configuración en archivos properties; las credenciales viven en un archivo .env no versionado. Cada fila de un CSV es una ejecución de la prueba.
  • Verificación/Assert: acción que realiza el script para corroborar si hubo un error funcional (interfaz IVerify).
  • Framework: automation-framework, con Factory y Singleton para el navegador (interfaz IBrowser) y Page Object Model (paquetes pom, task y data por pantalla).
  • JUnit 5: ejecuta las pruebas y las agrupa en suites mediante etiquetas (@Tag).
  • Allure: registra los resultados de cada ejecución para generar reportes con métricas.
  • Selenium: permite manipular el navegador como lo haría un usuario manual.
  • Drivers (Chrome y Firefox): crean la instancia del navegador usada por Selenium.

Suites ejecutadas

  • Suite completa (regresión): las 4 suites siguientes
  • Crear cuenta Administrador
  • Reiniciar contraseña
  • Crear cuenta Tester
  • Eliminar cuenta Tester

También existen las suites SuiteHumo (pruebas mínimas, etiqueta humo), SuiteCuentasAdministrador y SuiteCuentasTester, que agrupan por etiqueta.
